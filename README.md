# Spec-driven development: a worked example

A small, self-contained example of how I work as a product owner when engineers build with AI coding agents: the **spec is the source of truth**, and the code is implemented from it.

> Everything here is fictional. "Nimbus" is an invented B2B marketplace where resellers buy cloud subscriptions from vendors. No real company, customer or vendor data is used.

## What's in here

| Path | What it is |
|---|---|
| [`specs/001-seat-change-proration/spec.md`](specs/001-seat-change-proration/spec.md) | The spec: context, requirements, decision table, edge cases, acceptance criteria, scope, assumptions, solution |
| `AGENTS.md` | Rules for coding agents working from the spec |
| `src/`, `tests/` | The implementation and tests built from the spec |

## The feature

A reseller changes the number of seats on a monthly subscription in the middle of a billing cycle. It sounds simple; it is where billing errors usually come from: proration, rounding, vendor-specific rules for decreases, seat limits, and retries that charge twice.

## How the spec is built

One page, two owners:

- **Product** writes Context, Requirements, Scope and Assumptions.
  - Every requirement has an ID and stands on its own.
  - A decision table covers the combinations, so nobody has to infer them.
  - Acceptance criteria are Given/When/Then, and each names the requirements it verifies.
  - Each assumption says which requirement changes if it turns out to be wrong.
- **Tech design** writes the Solution: decisions with the rejected alternative, the contract, and the task list.

Engineers then implement from the spec with a coding agent. If behaviour needs to change, the spec changes first.

## Traceability

Every requirement ID in the spec appears in at least one test name or docstring. `tests/test_traceability.py` fails the build if a requirement has no test.

## Run it

```bash
python -m pytest
```

Python 3.10+, no dependencies beyond `pytest`.

## How this was made

The spec was drafted with Claude and reviewed and edited by me. The implementation and tests were generated by an AI coding agent from the spec. That is the point of the example.
